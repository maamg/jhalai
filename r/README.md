# R practice

Data-frame construction, selection, summary statistics and importing CSV, Excel and SPSS files.

Run in R/RStudio. `Lesson 3.R` needs `readxl` and `haven`, and currently points to a local Windows directory. Adjust both `setwd` calls for your machine. Supply your own `Author.csv`, `students.xlsx` and `Employee data.sav`; the local datasets have not been published. The original workbook was named `Students.xlsx`, so case matters on Linux. `View()` is intended for an interactive session.

`Learining with chatgpt.R` writes `student_data.csv` in the working directory.
