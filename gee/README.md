# Google Earth Engine

Two related JavaScript exercises filter `COPERNICUS/S2_HARMONIZED` by cloud cover, date and location. Paste an exercise into the Earth Engine Code Editor in an authorised Earth Engine account; `ee` and `Map` are supplied by that environment.

The scripts currently use dates in 2019; the comment asking for September 2023 is an unfinished exercise. The final chained example omits the bounds filter. These are practice snapshots, not a finished classification workflow.
